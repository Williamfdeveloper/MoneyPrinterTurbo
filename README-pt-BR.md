# MoneyPrinterTurbo 💸

### Um gerador completo de vídeos curtos com IA

Informe um <b>tema</b> ou <b>palavra-chave</b> para o vídeo e o MoneyPrinterTurbo gera o roteiro, encontra as imagens, cria as legendas e a música de fundo e produz um vídeo curto em alta definição.

## Recursos 🎯

### Fluxos de criação

- [x] Use fluxos com **agente de IA, WebUI, API ou CLI** para criar rápido ou produzir de forma automatizada
- [x] Vá do tema ao roteiro, narração, imagens, legendas, música e edição de forma automática, mantendo o controle de cada etapa
- [x] Gere várias versões em lote, consulte o histórico de tarefas e importe ou exporte configurações de geração e chaves de API

### Roteiros e provedores de modelos

- [x] Gere ou reescreva **roteiros de vídeo em vários idiomas** com IA, ou forneça um roteiro completo seu
- [x] Use os principais provedores, incluindo [Kimi / Moonshot AI](https://platform.kimi.ai?track_id=track-9e3b711aa2594e378f6fe5b8de718a76&aff=moneyprinterturbo), [OpenAI](https://platform.openai.com/api-keys), [Anthropic Claude](https://platform.claude.com/settings/keys), [Google Gemini](https://aistudio.google.com/app/apikey), [DeepSeek](https://platform.deepseek.com/api_keys), [Alibaba Cloud Qwen](https://qwen.ai/apiplatform), [Microsoft Azure OpenAI](https://portal.azure.com/#view/Microsoft_Azure_ProjectOxford/CognitiveServicesHub/~/OpenAI), [ByteDance VolcEngine Ark](https://console.volcengine.com/ark), [xAI Grok](https://console.x.ai/), [MiniMax](https://platform.minimax.io/) e [Xiaomi MiMo](https://platform.xiaomimimo.com/docs/zh-CN/quick-start/first-api-call)
- [x] Conecte-se por [Shengsuan Cloud](https://www.shengsuanyun.com/?from=CH_XUQ4OTSK), [APIMart](https://go.apimart.ai/gh-moneyprinterturbo), [Cloudflare AI Gateway](https://dash.cloudflare.com/), [Alibaba ModelScope](https://modelscope.cn/docs/model-service/API-Inference/intro), [AIHubMix](https://aihubmix.com/), [AIML API](https://aimlapi.com/app/keys), [EvoLink](https://evolink.ai/dashboard/keys), [OpenRouter](https://openrouter.ai/settings/keys), [API Route](https://www.api-route.com/), [Ollama](https://ollama.com/), [assinatura do Claude Code](https://code.claude.com/docs), [OneAPI](https://github.com/songquanpeng/one-api), [LiteLLM](https://docs.litellm.ai/docs/providers), [Groq](https://console.groq.com/keys), [Pollinations AI](https://enter.pollinations.ai/) e outros gateways compatíveis ou execuções locais

### Imagens e vídeos

- [x] Envie suas próprias **imagens e vídeos locais** ou use vídeos de banco em HD da [Pexels (grátis)](https://www.pexels.com/api/), [Pixabay (grátis)](https://pixabay.com/api/docs/) e [Coverr](https://coverr.co/developers?ctx=header_navigation)
- [x] Gere imagens de origem em `768P` ou `2K` com o [Metaso MiniMax H3](https://metaso.cn/minimax-h3/?s=MPT), em clipes de 4 a 15 segundos nas proporções `9:16`, `16:9` ou `1:1`
- [x] Crie vários clipes de vídeo com IA no [Shengsuan Cloud AI Video](https://www.shengsuanyun.com/?from=CH_XUQ4OTSK) e combine-os com o fluxo de narração, legendas e edição do projeto
- [x] Use a integração nativa com o [Volcano Engine Ark Seedance](https://console.volcengine.com/ark/region:ark+cn-beijing/apikey) para gerar imagens coerentes a partir de cada trecho do roteiro
- [x] Transforme as palavras-chave do roteiro em vídeos originais com o [WaveSpeed AI](https://wavespeed.ai)
- [x] Acesse Seedance, Wan e outros modelos de texto para vídeo pela [OFox](https://ofox.ai) com uma única chave de API
- [x] Gere materiais de vídeo com IA de 3 a 12 segundos pela API assíncrona de texto para vídeo da [MuAPI](https://muapi.ai), com endpoint, proporção, resolução e polling configuráveis
- [x] Conecte serviços de [texto para imagem compatíveis com OpenAI](https://platform.openai.com/docs/guides/image-generation) ou gateways de imagem próprios e transforme as imagens geradas em clipes animados
- [x] Ajuste a duração dos clipes, o encaixe do quadro e a ordem dos materiais para diferentes proporções e estilos de narrativa

### Narração, legendas e música de fundo

- [x] Escolha narração automática, áudio enviado ou nenhuma narração, com amostras de voz e prévia da narração completa
- [x] Use **Edge TTS (grátis, sem chave de API)**, Azure Speech, SiliconFlow, Google Gemini, Xiaomi MiMo, MiniMax, ElevenLabs, Chatterbox, Kokoro, Fish Audio, ModelBest VoxCPM e outros serviços de voz
- [x] Gere legendas e configure fonte, posição, cor, tamanho, contorno e estilo do fundo
- [x] Use música de fundo aleatória, local ou gerada por IA, com controle de volume independente

### Saída e publicação

- [x] Exporte vídeos na vertical `9:16 (1080×1920)`, na horizontal `16:9 (1920×1080)` ou quadrados `1:1 (1080×1080)`
- [x] Publique os vídeos prontos direto no **TikTok, Instagram e YouTube Shorts**

## Requisitos do sistema 📦

- Plataformas recomendadas: Windows 10+, macOS 11+ ou uma distribuição Linux popular
- A instalação local exige Python 3.11 ou mais recente; recomenda-se o Python 3.11
- GPU não é obrigatória, mas é recomendada se você quiser transcrição local mais rápida, processamento de vídeo mais rápido ou geração em lote mais fluida

| Item | Mínimo           | Recomendado     | Ideal         |
| ---- | ---------------- | --------------- | ------------- |
| CPU  | 4 núcleos        | 6 a 8 núcleos   | 8+ núcleos    |
| RAM  | 4 GB             | 8 GB            | 16+ GB        |
| GPU  | Não é necessária | 4+ GB de VRAM   | 8+ GB de VRAM |

- Se você usa principalmente LLMs na nuvem, TTS na nuvem e fontes de materiais on-line, CPU e RAM importam mais que a GPU
- Se você usa `faster-whisper`, geração em lote ou processamento local mais pesado, uma GPU melhora bastante o desempenho

## Instalação e implantação 📥

### Instale o pacote oficial com pip

O pacote oficial no PyPI é o **[mpt](https://pypi.org/project/mpt/)**,
mantido por `harry0703`. O pacote `MoneyPrinterTurbo` no PyPI é mantido por terceiros.

Não é preciso clonar o repositório. Exige Python 3.11 ou mais recente; recomenda-se o Python 3.11.

**① Crie e ative um ambiente virtual**

macOS / Linux:

```shell
python3 -m venv .venv
source .venv/bin/activate
```

Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**② Instale e inicie**

```shell
python -m pip install mpt
mpt webui
```

A WebUI abre automaticamente no navegador. Use `mpt webui --port 8503 --headless`
para escolher uma porta sem abrir o navegador. Para gerar vídeos pela CLI, veja `mpt cli --help`.

**③ Configure os serviços e encontre seus arquivos**

O aplicativo cria o `config.toml` na primeira execução. Adicione as chaves de API
necessárias para modelos on-line, imagens ou serviços de voz nas configurações básicas da WebUI.
Por padrão, o aplicativo instalado guarda a configuração e os arquivos gerados em:

| Sistema | Diretório de dados |
| --- | --- |
| macOS | `~/Library/Application Support/MoneyPrinterTurbo` |
| Windows | `%LOCALAPPDATA%\MoneyPrinterTurbo` |
| Linux | `~/.local/share/MoneyPrinterTurbo` ou `$XDG_DATA_HOME/MoneyPrinterTurbo` |

Defina `MPT_HOME` antes de iniciar para escolher outro diretório. Os vídeos gerados ficam em
`storage/tasks` dentro desse diretório. Para atualizar, ative o ambiente virtual e
rode `python -m pip install --upgrade mpt`.

### Pré-requisitos para instalar a partir do código-fonte

- A instalação local exige Python 3.11 ou mais recente
- No Windows, evite caminhos de projeto com caracteres não ASCII (como acentos), caracteres especiais ou espaços

#### ① Clone o projeto

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
```

#### ② Faça a configuração inicial

Na primeira execução, o projeto cria o `config.toml` a partir do `config.example.toml`, então você não precisa criar o arquivo manualmente. Antes de usar LLMs na nuvem, imagens on-line ou serviços de vídeo com IA, adicione as chaves de API correspondentes nas configurações básicas da WebUI.

### Instalação com Docker 🐳

#### ① Inicie o contêiner Docker

Se o Docker não estiver instalado, [baixe e instale o Docker Desktop](https://www.docker.com/products/docker-desktop/) primeiro.
Se você usa Windows, consulte a documentação da Microsoft:

1. [Instalar o WSL](https://learn.microsoft.com/pt-br/windows/wsl/install)
2. [Usar contêineres Docker com o WSL](https://learn.microsoft.com/pt-br/windows/wsl/tutorials/wsl-containers)

```shell
cd MoneyPrinterTurbo
docker compose -f docker-compose.release.yml up
```

> O padrão recomendado é o `docker-compose.release.yml`, que baixa a imagem pronta do GitHub Container Registry: `ghcr.io/harry0703/moneyprinterturbo:latest`.
> Se precisar gerar a imagem localmente, você ainda pode rodar `docker compose up`.
> Antes da primeira execução, copie o `config.example.toml` para `config.toml` para que ele possa ser montado nos contêineres.

#### ② Acesse a WebUI

Abra o navegador e acesse http://127.0.0.1:8501

#### ③ Acesse a documentação da API

Abra o navegador e acesse http://127.0.0.1:8080/docs ou http://127.0.0.1:8080/redoc

> Por padrão, a API permite acesso do navegador apenas na mesma origem. Defina a variável de ambiente `CORS_ALLOWED_ORIGINS` só quando um frontend separado precisar chamar a API direto de outra origem, por exemplo `http://localhost:3000,https://frontend.example.com`. O CORS não afeta curl, Postman, n8n ou outros clientes do lado do servidor.

### Instalação manual 📦

#### ① Crie um ambiente virtual Python

Use o [uv](https://docs.astral.sh/uv/) para gerenciar o ambiente Python e as dependências. O projeto suporta Python 3.11 ou mais recente; o exemplo abaixo usa o Python 3.11.

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen
```

Se você ainda não usa o `uv`, pode usar `venv + pip`.

```shell
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Observações:

- O `pyproject.toml` agora é o principal arquivo de dependências.
- O `uv.lock` fixa o ambiente resolvido, por isso `uv sync --frozen` é o recomendado por padrão.
- O `requirements.txt` é mantido só para a instalação antiga com `pip`.

#### ② Inicie a WebUI 🌐

Os comandos abaixo precisam ser executados no `diretório raiz` do projeto MoneyPrinterTurbo

###### Windows

```powershell
.\webui.bat
```

Você também pode rodar o `webui.bat` no CMD.
O `webui.bat` dá preferência ao `.venv` do projeto ou ao Python que vem no pacote portátil. Se nenhum Python do projeto for encontrado mas o `uv` estiver instalado, ele usa automaticamente `uv run streamlit`.
Para permitir que outros dispositivos da sua rede local acessem a WebUI, rode `set MPT_WEBUI_HOST=0.0.0.0` antes do `webui.bat`.

###### macOS ou Linux

```shell
sh webui.sh
```

O script usa automaticamente o ambiente virtual do projeto ou o `uv` e escolhe uma porta local livre. Para permitir acesso de outros dispositivos da sua rede local, rode:

```shell
MPT_WEBUI_HOST=0.0.0.0 sh webui.sh
```

Depois de iniciar, o navegador abre automaticamente

#### ③ Inicie o serviço de API 🚀

```shell
uv run python main.py
```

Se você já ativou o ambiente virtual manualmente, também pode rodar:

```shell
python main.py
```

#### ④ Modo somente CLI (sem navegador) ⌨️

Se você não pode usar um navegador nem redirecionamento de porta, gere vídeos direto pela
linha de comando. O comando completo mais simples é:

```shell
uv run python cli.py --video-subject "Como a IA está mudando o dia a dia"
```

As opções de estilo de legenda e de narração são resolvidas nesta ordem: **opção explícita da CLI >
valor `[ui]` salvo no `config.toml` > padrão interno**. As outras configurações de geração,
como música de fundo, quantidade de vídeos e de parágrafos, não são herdadas da
WebUI. Se a WebUI estiver configurada para usar áudio enviado, passe `--custom-audio-file`
explicitamente, porque o caminho do arquivo enviado não é salvo.

Para a referência completa de comandos, a descrição dos parâmetros e as instruções de uso,
rode:

```shell
uv run python cli.py --help
```

Para rodar várias tarefas em sequência, passe um manifesto UTF-8 em array JSON ou JSONL. As
opções da CLI valem como padrão, e cada objeto sobrescreve campos de `VideoParams`:

```json
[
  { "video_subject": "Como funcionam os painéis solares" },
  { "video_subject": "Como funcionam as turbinas eólicas", "video_aspect": "16:9" }
]
```

```shell
uv run python cli.py --batch-file ./tasks.json --stop-at video
```

O manifesto é procurado a partir do diretório de trabalho atual. Valores relativos de
`custom_audio_file` e de `video_materials[].url` locais dentro dele são resolvidos
a partir do diretório do manifesto; caminhos de arquivo passados como padrão na CLI mantêm o
comportamento normal, relativo ao diretório de trabalho atual. Um manifesto é limitado a 100 tarefas e 1 MiB.
Todas as entradas são validadas antes de a primeira tarefa começar, as tarefas continuam mesmo se
uma delas falhar durante a execução, e o comando imprime um resumo em JSON ao terminar.
O resumo contém `total`, `succeeded`, `failed` e `tasks`; cada tarefa tem
`index`, `task_id`, `status`, `result`, `failed_stage` e `error`.

## Narração, legendas e música de fundo 🎙️

### Síntese de voz

A velocidade da fala no ElevenLabs depende do modelo escolhido. O padrão `eleven_multilingual_v2` aceita de 0,7× a 1,2×; escolha `eleven_v3` para a faixa REST mais ampla, de 0,25× a 4,0×. O MoneyPrinterTurbo avisa sobre escolhas não suportadas antes de enviar o pedido de geração e mantém a velocidade escolhida sem arredondá-la para dentro da faixa. Velocidades fora do padrão em `eleven_v4`/`eleven_v4_turbo` não são suportadas. Outros IDs de modelo usam uma faixa de validação conservadora de 0,7× a 1,2×; isso não garante que todo modelo suporte o ajuste de velocidade. Se o provedor retornar `invalid_voice_settings`, a geração para sem tentar de novo e mostra a explicação dele. A [validação em produção de v2/v3 relatada pelo mantenedor](https://github.com/harry0703/MoneyPrinterTurbo/pull/1578#issuecomment-6040107858) prevalece sobre a faixa mais ampla descrita na [referência oficial de configurações de voz](https://github.com/elevenlabs/skills/blob/main/text-to-speech/references/voice-settings.md).

O **Azure TTS V1** da WebUI usa o **Edge TTS** por baixo e é gratuito, sem chave de API. O MoneyPrinterTurbo também suporta **Azure TTS V2**, **SiliconFlow TTS**, **Google Gemini TTS**, **Xiaomi MiMo TTS**, **MiniMax TTS**, **ElevenLabs TTS**, **Chatterbox TTS** auto-hospedado, **Kokoro TTS** auto-hospedado, **Fish Audio TTS**, [ModelBest VoxCPM TTS](https://platform.modelbest.cn/console/docs/api/audio) e um modo sem voz.

Escolha um provedor e uma voz na WebUI e siga as instruções na tela para as credenciais necessárias. O Edge TTS não precisa de chave de API; o [Azure TTS V2](https://portal.azure.com/) e outros provedores na nuvem exigem credenciais das respectivas plataformas. Veja as vozes disponíveis do Edge TTS na [lista de vozes](./docs/voice-list.txt).

O ModelBest VoxCPM exige uma chave de API e um ID de modelo com a capacidade `speech_synthesis`. A resposta SSE dele transmite áudio WAV, que o MoneyPrinterTurbo converte automaticamente para o MP3 usado no fluxo de vídeo. Além do texto para fala padrão, a WebUI pode clonar a identidade de quem fala a partir de um áudio de referência opcional. A interpretação de alta fidelidade reutiliza esse trecho com a transcrição exata por padrão, ou aceita outro exemplo de interpretação, e envia `prompt_audio` com `prompt_text` para seguir o ritmo, a emoção e a pronúncia. A WebUI pode usar a configuração local do Whisper para criar um rascunho editável da transcrição. O envio é limitado a 20 MiB e cada WAV convertido a 5 MiB. O material de referência vale só para a sessão do navegador e a tarefa atuais e não é gravado na configuração, em predefinições, no histórico de tarefas nem nos logs.

### Geração de legendas

Há dois modos de geração de legendas:

- **edge**: usa os carimbos de tempo do TTS, roda rápido sem GPU e é o modo padrão.
- **whisper**: usa a transcrição local do `faster-whisper` quando você precisa de uma linha do tempo de legendas mais precisa. O modelo é baixado no primeiro uso.

Defina `subtitle_provider` no `config.toml` para trocar de modo. Por padrão, o Whisper usa o modelo `large-v3`, de cerca de 3 GB. Para usar o modelo `large-v3-turbo`, menor e mais rápido, com cerca de 1,6 GB:

```toml
[app]
subtitle_provider = "whisper"

[whisper]
model_size = "large-v3-turbo"
```

> No primeiro uso, o Whisper baixa o modelo automaticamente do Hugging Face. Se o download automático falhar, baixe o `whisper-large-v3` manualmente no [Hugging Face](https://huggingface.co/Systran/faster-whisper-large-v3).

Depois de extrair o modelo, coloque o diretório inteiro em `.\MoneyPrinterTurbo\models`. O caminho final deve ser `.\MoneyPrinterTurbo\models\whisper-large-v3`:

```
MoneyPrinterTurbo
  ├─models
  │   └─whisper-large-v3
  │          config.json
  │          model.bin
  │          preprocessor_config.json
  │          tokenizer.json
  │          vocabulary.json
```

## Perguntas frequentes 🤔

<details>
<summary>RuntimeError: No ffmpeg exe could be found</summary>

Normalmente, o ffmpeg é baixado e detectado automaticamente.
Mas, se algo no seu ambiente impedir o download automático, pode aparecer este erro:

```
RuntimeError: No ffmpeg exe could be found.
Install ffmpeg on your system, or set the IMAGEIO_FFMPEG_EXE environment variable.
```

Nesse caso, baixe o FFmpeg em [gyan.dev](https://www.gyan.dev/ffmpeg/builds/), extraia e defina `ffmpeg_path` com
o caminho real da instalação.

```toml
[app]
# Ajuste para o seu caminho real; no Windows, o separador de caminho é \\
ffmpeg_path = "C:\\Users\\harry\\Downloads\\ffmpeg.exe"
```

</details>

<details>
<summary>OSError: [Errno 24] Too many open files</summary>

Este problema é causado pelo limite do sistema para a quantidade de arquivos abertos. Você pode resolvê-lo aumentando esse limite.

Veja o limite atual:

```shell
ulimit -n
```

Se estiver baixo demais, aumente, por exemplo:

```shell
ulimit -n 10240
```

</details>
